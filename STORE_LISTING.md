A lightweight sidebar for Swagger UI pages that makes large API docs easier to navigate.

**What it does**

Swagger UI is great for a handful of endpoints — but once an API has dozens or hundreds, scrolling through the page to find what you need gets tedious. Endpoint Atlas adds a fixed sidebar to every Swagger UI page with:

- A collapsible, grouped list of every endpoint, with HTTP method and count badges
- A filter box that searches by path, method, or tag and auto-expands matching groups
- One-click navigation — selecting an endpoint expands it in the main view and scrolls it into focus
- A live auth status indicator that opens the Authorize dialog when clicked

**How to use it**

Install the extension and open any Swagger UI page. The sidebar appears automatically — no configuration, no setup, no account.

**Privacy**

Endpoint Atlas does not collect, store, or transmit any data. It runs entirely in your browser, reads only the Swagger UI page you have open, and makes no network requests of its own. There is no analytics, no telemetry, and no remote server.
